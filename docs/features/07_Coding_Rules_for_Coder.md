# 07_Coding_Rules_for_Coder.md

## 1. コーディング規約
Coderはコードを改修する際、以下のルールを厳守してください。

* **Vanilla JSの維持:** ReactやVueなどの外部フレームワークは導入せず、既存のVanilla JS構成とカスタムコンポーネント（Custom Elements）の枠組みを維持すること。
* **属性バインディングの活用:** DOMの直接操作は極力避け、`CoreUIPatcher` の仕組み (`data-out`, `data-action`) を利用してState経由でUIを更新すること。
* **コメントとプロパティ名の保持:** `CoreState.html` 内の `GLB` など、既存のコメントアウトやプロパティ名は認知度向上のため文字数制限を撤廃して維持されています。リファクタリング時もこれらを絶対に削除・短縮しないでください。
* **エラーハンドリング:** GASとの通信や非同期処理 (`CoreAct.withAsync`) を用いる際は、既存のラッパーと例外処理パターンに従うこと。

## 2. セキュリティ・コーディング規約
* **DOM Based XSSの防止 (数式評価):**
  悪意あるコードがアプリを介して入力・実行されるのを防ぐため、数式の評価において `new Function` を使用することは絶対に禁止します。指数計算等の評価エンジンには、セキュアな外部ライブラリである `math.js` をCDNから読み込んで使用してください。
