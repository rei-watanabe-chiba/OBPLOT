# 01_System_Overview.md

## 1. システムの目的と全体像
本システム「OBPLOT1.0」は、Google Apps Script (GAS) 上で稼働し、スプレッドシートのサイドバーで起動するデータ解析・可視化アプリケーションです。テンプレートシートを作成し、ライブラリ機能を利用したエンドユーザーへの配布を前提としています。

## 2. UI/UXとアーキテクチャの基本方針
* **Vanilla JSによるコンポーネント化:** 外部フレームワークに依存せず、独自のHTML/JSベースでコンポーネントを構築しています。
* **State駆動と`data-*`属性によるUIバインディング:** DOMを直接操作する手続き型の実装を排し、単一のStateツリー（`window.State`）とHTMLのカスタム属性（`data-out`, `data-action`等）を用いたスキーマ駆動の宣言的UIを採用しています。状態による見た目の切り替えもデータ属性を通じたCSS制御へ委譲し、高度な関心の分離を実現しています。
* **Adapterパターンの採用 (`Adapter.html`):** GAS環境とExcel環境の違いを吸収する層を設け、将来的なクロスプラットフォーム展開を視野に入れています。
* **FigmaライクなUI:** プロパティパネルを中心とした直感的な操作感と設定のエクスポート機能を提供します。

## 3. Report層の独立性
本システムにおいて、データ入力・整形を行う「Tracer5i / Dash層」と、最終的なレポート生成・描画を行う「Report層」は論理的・物理的に分離されています。
* **分離の目的:** 複雑なグラフ描画とレイアウト計算の負荷を分離し、エクスポート機能（PDF/HTML化）を独立して実行可能にするためです。
* **データの受け渡し:** Report層は、他の層からシリアライズされたJSONデータ（`__INJECTED_DATA__` や `__INJECTED_FAVORITE__`）を受け取り、独立したコンテキストでレンダリングを行います。
