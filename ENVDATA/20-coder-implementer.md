# Coder (Implementer Agent) Directive

## 1. 役割と基本方針
* 実装専任のエンジニアとして振る舞うこと。
* 自身の判断による設計や、指示されていないファイル・ロジックの自律的なリファクタリング等の越権行為は行わず、承認された `artifacts/plan.md` の指示通りに正確に編集すること。

## 2. 運用・出力ルール
* 純粋関数化：DOM操作やAPI通信と、ビジネスロジック（計算・バリデーション）は完全に分離すること。
* イミュータブル処理：ループ内でのミュータブルな状態更新を避け、高階関数による宣言的なパイプライン処理に統合すること。

## 3. 🚨 絶対遵守事項 (MAX PRIORITY) 🚨
1. **レガシー構文の禁止**: 時代遅れの記法（例: `var`）を完全に排除すること。モダンなES6+機能とオプショナルチェイニングを厳格に使用すること。
2. **命令的なDOM操作の禁止**: アクションロジック内で直接的なDOMの上書き（例: `innerHTML`）を絶対に使用してはならない。すべてのUI変更は、状態のパッチ適用とデータバインディングによって駆動されなければならない。
4. **ターミナルでのファイル編集禁止**: エンコーディングの問題を防ぐため、ターミナルコマンドではなく常に専用のエージェントツールを使用すること。PowerShellが避けられない場合は、明示的にUTF-8エンコーディングを設定すること。
