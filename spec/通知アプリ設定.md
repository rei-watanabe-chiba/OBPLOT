# AppSheet Step 2 承認ワークフロー ＆ 画面UI構築 実装手順書 (v7)

## 1. 本手順書の目的と前提事項

### 1.1 概要
本書は「緊急連絡・休業通知システム」の構築ロードマップにおける **Step 2（AppSheet 承認ワークフロー ＆ UI構築）** の具体的な実装手順を解説するマニュアルである。

### 1.2 AppSheet 仕様に準拠した UI 日本語化設計（重要）
* **Enum（選択肢）の日本語化と Bot 側でのコード変換**:
  AppSheet の Enum 設定（Values）には選択肢ごとに個別の `Display Name` を設定するプロパティが存在しないため、**AppSheet の Enum 選択肢（Values）には直接「日本語テキスト」（例: `職員`, `補助員`, `全員` など）を設定**します。
  GAS / FCM への送信が必要なパラメータについては、**AppSheet Bot（`Call a script` タスク）の引数マッピング数式内で `SWITCH` や `IFS` 関数を用いて英語コード（`staff`, `assistant`, `timer`, `immediate` 等）へ自動変換して送信**します。
* **項目削除（`is_protected` の廃止）**:
  保護機能は「配信対象（`target_group`）」の設定によって代替・明確化できるため、`is_protected` カラムは不要とし、スキーマ・フォーム・Botパラメータから完全に削除・除外します。
* **GWS管理者設定氏名の活用 (`USERNAME()`)**:
  Google Workspace (GWS) 管理者がアカウントに設定した表示名を AppSheet の **`USERNAME()`** 関数で動的取得します。起案・承認ボタン押下時の「その瞬間の氏名」がテキストとしてスナップショット保存されるため、年度替わりの担当者交代があっても過去の起案者・承認者名が自動的に保護されます。
* **カラム名の標準化**: 起案者カラムは短く分かりやすい名称として **`drafter`（起案者メール）** および **`drafter_name`（起案者氏名）** を使用します。

## 2. データベース（スプレッドシート）ヘッダー構成

Google ドライブ上のバックエンド用スプレッドシートに、以下の3つのシートを作成・更新します。（※ `is_protected` は除外）

### ① `Notices` シート（1行目ヘッダー推奨列順）
> `notice_id` | `title` | `body` | `target_group` | `priority` | `remarks` | `selected_approvers` | `status` | `send_option` | `scheduled_send_time` | `deletion_type` | `drafter` | `drafter_name` | `created_at` | `updated_at` | `fiscal_year`

### ② `ApprovalLogs` シート（1行目ヘッダー列順）
> `log_id` | `notice_id` | `approver_email` | `approver_name` | `action_type` | `comment` | `created_at`

### ③ `UserMaster` シート（1行目ヘッダー列順）
> `user_email` | `user_name` | `role` | `is_active`

## 4. AppSheet 承認ワークフロー ＆ アクションの実装手順

AppSheet の `Data > Actions` にて作成するボタン・アクションの設定値です。

### 4.1 アクション定義一覧

#### ① 【起案者】「申請」アクション
* **Action Name**: `Submit_Notice`
* **Target Table**: `Notices`
* **Do this**: `Set the values of some columns in this row`
* **Set Columns**:
  * `status` ➔ `"申請待ち"`
* **Only if this condition is true**:
  ```excel
  AND(
    [drafter] = USEREMAIL(),
    OR([status] = "下書き", [status] = "修正指示"),
    ISNOTEMPTY([selected_approvers])
  )
  ```

#### ② 【承認者】「修正指示（コメント付き）」アクション
* **Action Name**: `Request_Revision`
* **Target Table**: `Notices`
* **Do this**: `Grouped: execute a sequence of actions`
  1. `ApprovalLogs` 行追加アクション（`action_type` = `"修正指示"`）
  2. `Notices` の `status` を `"修正指示"` に更新するアクション
* **Only if this condition is true**:
  ```excel
  AND(
    IN(USEREMAIL(), [selected_approvers]),
    OR([status] = "申請待ち", [status] = "削除申請中")
  )
  ```

#### ③ 【承認者】「承認」アクション
* **Action Name**: `Approve_Notice`
* **Target Table**: `Notices`
* **Do this**: `Set the values of some columns in this row`
* **Set Columns**:
  * `status` ➔
    ```excel
    IF(
      COUNT(SELECT(ApprovalLogs[approver_email], AND([notice_id] = [_THISROW].[notice_id], [action_type] = "承認"))) + 1 >= COUNT([selected_approvers]),
      "送信待ち",
      "申請待ち"
    )
    ```
  * ※同時に `ApprovalLogs` に `action_type` = `"承認"` の行を追加。
* **Only if this condition is true**:
  ```excel
  AND(
    IN(USEREMAIL(), [selected_approvers]),
    OR([status] = "申請待ち", [status] = "削除申請中"),
    NOT(IN(USEREMAIL(), SELECT(ApprovalLogs[approver_email], [notice_id] = [_THISROW].[notice_id])))
  )
  ```

#### ④ 【起案者】「一斉送信を実行（10分タイマー / 緊急即時）」アクション
* **Action Name**: `Execute_Send`
* **Target Table**: `Notices`
* **Do this**: `Set the values of some columns in this row`
* **Set Columns**:
  * `status` ➔ `IF([send_option] = "緊急即時送信", "施行済み", "送信予約")`
  * `scheduled_send_time` ➔ `IF([send_option] = "緊急即時送信", NOW(), NOW() + "000:10:00")`
* **Only if this condition is true**: `[status] = "送信待ち"`

## 5. AppSheet Automation Bot ＆ GAS コード変換連携設定

### 5.1 Bot (`Send_FCM_Bot`) の設定手順

1. `Automation > Bots` で **「Create a new bot」** をクリック。
2. **Event 設定**:
   * **Event Name**: `Notice_Status_Changed`
   * **Table**: `Notices`
   * **Data Change Type**: `Updates_Only`
   * **Condition**:
     ```excel
     OR(
       [status] = "施行済み",
       [status] = "取消済み",
       [status] = "完全削除済み",
       [status] = "申請待ち",
       [status] = "修正指示",
       [status] = "送信待ち"
     )
     ```
3. **Task 設定 (`Call a script`)**:
   * **Task Name**: `Trigger_GAS_FCM_and_Log`
   * **Task Type**: `Call a script`
   * **Apps Script Project**: GASの**スクリプト ID**を貼り付けて検索・選択。
   * **Function Name**: **`sendFcmNotification`**
   * **Function Parameters (日本語EnumからGAS用英語コードへの自動変換マッピング)**:
     * `noticeId` ➔ `[notice_id]`
     * `title` ➔ `[title]`
     * `body` ➔ `[body]`
     * `targetGroup` ➔
       ```excel
       SWITCH([target_group],
         "職員", "staff",
         "補助員", "assistant",
         "all"
       )
       ```
     * `sendOption` ➔
       ```excel
       IF([send_option] = "緊急即時送信", "immediate", "timer")
       ```
     * `actionType` ➔
       ```excel
       IFS(
         [status] = "施行済み", "send",
         [status] = "取消済み", "invalidate",
         [status] = "完全削除済み", "silent_delete",
         TRUE, "approval_log"
       )
       ```
     * `deletionType` ➔
       ```excel
       IF([deletion_type] = "取消（アプリで無効化表示）", "invalidate", "silent_delete")
       ```
     * `approverEmail` ➔ `USEREMAIL()`
     * `approverName` ➔ `USERNAME()`
     * `comment` ➔ `INDEX(SELECT(ApprovalLogs[comment], AND([notice_id] = [_THISROW].[notice_id], [approver_email] = USEREMAIL())), 1)`

## 6. UI画面（Views） ＆ アクセス制御（Security Filter）の構築

### 6.1 プライマリビュー（3大画面）の設定

1. **「起案一覧」View (Table View)**:
   * **Slice (フィルタ)**: `status` ∈ {`"下書き"`, `"申請待ち"`, `"修正指示"`, `"送信待ち"`, `"送信予約"`}
2. **「決裁」View (Table View)**:
   * **Slice (フィルタ)**: `IN(USEREMAIL(), [selected_approvers])` かつ `status` ∈ {`"申請待ち"`, `"修正指示"`, `"削除申請中"`}
3. **「施行済み一覧」View (Grouped Table View)**:
   * **Slice (フィルタ)**: `status` ∈ {`"施行済み"`, `"取消済み"`}
   * **Group by**: `fiscal_year` (降順)

### 6.2 画面表示・編集制御数式

* **起案フォームの編集許可 (`Editable_If`)**:
  ```excel
  AND(
    [drafter] = USEREMAIL(),
    OR([status] = "下書き", [status] = "修正指示")
  )
  ```
* **`Notices` テーブルの Security Filter**:
  ```excel
  OR(
    [drafter] = USEREMAIL(),
    IN(USEREMAIL(), [selected_approvers]),
    [status] = "施行済み",
    [status] = "取消済み"
  )
  ```

## 7. HTML受信用テストページ ＆ スプレッドシートデバッグ検証手順

1. **AppSheet アプリ上で「起案」作成**:
   * 件名「【台風に伴うテスト休校】」、本文を入力し、配信対象を「職員」、優先度を「緊急」にセット。承認者を指定して「申請」をタップ。
2. **スプレッドシート「実行ログ」シートのデバッグログ確認**:
   * アクション `approval_log` として、操作者（`USEREMAIL()` / `USERNAME()`）・`申請待ち` ステータス移行が記録されていることを確認。
3. **承認者アカウントで「決裁」画面から「承認」を実行**:
   * ステータスが `送信待ち` に更新され、ログシートに承認者コメントと承認イベントが記録される。
4. **「一斉送信」を実行（`status = "施行済み"`）**:
   * AppSheet Bot のコード変換数式により `targetGroup = "staff"`, `actionType = "send"` に自動変換されて GAS が起動。
   * スプレッドシート「実行ログ」シートに `[5/5 送信成功] FCM API応答 (200 OK)` が記録され、HTML受信用テストページへプッシュ通知が届くことを確認。
