## 3. AppSheet の設定明細（バックエンド ＆ テーブル構造）

### 3.1 バックエンドスプレッドシート構成
- **ファイル名**: `緊急連絡システム_DB` (Googleスプレッドシート)
- **シート構成**:
  1. `Notices` (メイン起案・施行テーブル)
  2. `ApprovalLogs` (決裁履歴・コメント用子テーブル)

## 5. 承認フローの数式 ＆ ガード制御設定

### 5.1 Security Filter (データアクセス制限)
**Notices テーブル**:
```excel
OR(
  [created_by] = USEREMAIL(),
  IN(USEREMAIL(), [selected_approvers]),
  [status] = "sent",
  [status] = "invalidated"
)
```

### 5.2 起案フォームの編集許可 (`Editable_If`)
**Notices テーブル**:
```excel
AND(
  [created_by] = USEREMAIL(),
  OR([status] = "draft", [status] = "revision_requested")
)
```

### 5.3 決裁フォームのアクション表示許可 (`Show_If`)
「承認」および「修正指示」ボタンの表示条件：
```excel
AND(
  IN(USEREMAIL(), [selected_approvers]),
  OR([status] = "pending", [status] = "revision_requested", [status] = "deletion_pending"),
  NOT(IN(USEREMAIL(), SELECT(ApprovalLogs[approver_email], [notice_id] = [_THISROW].[notice_id])))
)
```

### 5.4 「一斉送信」ボタンの表示許可 (`Show_If`)
全員の承認が完了（`status` = `"approved_pending_send"`）した際に出現：
```excel
AND(
  [status] = "approved_pending_send",
  OR(
    [created_by] = USEREMAIL(),
    IN(USEREMAIL(), [selected_approvers])
  )
)
```

## 6. AppSheet Automation (Bot / Task) 設定

AppSheet の **Automation** 画面で GAS 関数を直接呼び出すタスク（`Call a script`）を設定します。

```text
[ Bot : FCM Send Bot ]
  ├── Event : When status changes to "sent"
  │     Condition : AND([status] = "sent", [_THISROW_BEFORE].[status] <> "sent")
  └── Task : Call a script (Emergency-FCM-Direct)
        Function Name : sendFcmNotification
```

## 8. 承認フロー統合テスト実施手順

以下のステップで、起案から承認、FCM送信までのフルフローテストを実施します。

### テストステップ

1. **事前準備**:
   * ブラウザ右側にテスト画面（`fcm-web-push-test-code.html`）を開き、FCM Token を取得・確認しておきます。
   * GAS のスクリプトプロパティ `TEST_FCM_TOKEN` に上記トークンが設定されていることを確認します。

2. **Step 1: 新規起案の作成 (`draft` ➔ `pending`)**
   * AppSheet アプリの「起案一覧」から **「＋ 新規作成」** を押します。
   * 件名: `【承認テスト】台風に伴う臨時休業のお知らせ`
   * 本文: `明日9月11日は台風接近のため全館休業とします。`
   * 承認者: 自分（またはテスト用承認者）を選択。
   * **「申請する」** ボタンを押します ➔ ステータスが **`「承認待ち」 (pending)`** に遷移します。

3. **Step 2: 決裁・承認処理 (`pending` ➔ `approved_pending_send`)**
   * アプリの「決裁」一覧を開きます。
   * 該当の起案を選択し、確認コメントを入力して **「承認する」** ボタンを押します。
   * 設定された全員の承認が完了すると、ステータスが **`「承認済み（未送信）」 (approved_pending_send)`** に変わり、画面上部に **「🚀 一斉送信を実行」** ボタンが出現します。

4. **Step 3: 一斉送信の実行 (`approved_pending_send` ➔ `sent`)**
   * **「🚀 一斉送信を実行」** ボタンを押します。
   * 確認ダイアログで「OK」を選択します ➔ ステータスが **`「送信完了」 (sent)`** に更新されます。

5. **Step 4: 結果ログ ＆ 通知の受信検証**
   * **AppSheet / GAS 動作**: AppSheet Automation が起動し、`gas-fcm-direct-v3.gs` の `sendFcmNotification` 関数が 1 回だけ直接呼び出されます。
   * **スプレッドシート確認**: 「実行ログ」シートに `[1/5 呼び出し受信]` 〜 `[5/5 成功] FCM応答 (200 OK)` のログが正しく 1 行追加されます。
   * **テスト画面確認**: 横のテスト画面の「リアルタイム受信ログ」に、件名 `【承認テスト】台風に伴う臨時休業のお知らせ` の通知がリアルタイム表示されます。
